# 12. S2-1 컬렉션 설정(차원·거리)

## 이 수업에서 하는 일

- embed 도우미
- 차원을 코드로
- 나중에 바꾸기
- 크기는 못 바꾼다
- 과제 풀이

## 파일

- `compare.py`
- `embed.py`
- `setup.py`

수업이 끝났을 때의 모습 그대로입니다(녹화에서 직접 입력한 코드).

## 실행

저장소 루트에서 `uv sync`를 한 번 해 두고, Qdrant 서버(localhost:6333)를 켠 뒤 이 폴더에서 실행합니다.

```bash
cd lessons/12-S2-1
# 녹화에서 실행한 순서
uv run setup.py
uv run compare.py
```
