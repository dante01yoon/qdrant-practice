# 13. S2-2 포인트 ID 설계

## 이 수업에서 하는 일

- 상품 번호를 ID로?
- 줄 번호를 ID로 쓰면
- uuid5로 고정 ID
- 두 번 넣어도 그대로
- 상품 번호로 바로 꺼내기
- 과제 풀이

## 파일

- `ids.py`
- `labels.py`
- `lookup.py`

수업이 끝났을 때의 모습 그대로입니다(녹화에서 직접 입력한 코드).

## 실행

저장소 루트에서 `uv sync`를 한 번 해 두고, Qdrant 서버(localhost:6333)를 켠 뒤 이 폴더에서 실행합니다.

```bash
cd lessons/13-S2-2
# 앞 수업에서 만든 상태(컬렉션 등)를 먼저 만들어 둡니다. 앞 수업을 이미 따라왔다면 건너뛰어도 됩니다.
uv run python ../../scripts/warmup/warm_uuid.py

# 녹화에서 실행한 순서
uv run ids.py
uv run labels.py
uv run lookup.py
```
